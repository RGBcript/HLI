# HLI 0.9.0-beta.1

Primera distribución pública instalable de HLI.

## Incluye

- Runtime con event log verificado, snapshots, export/import.
- Runs síncronos y asíncronos con cancelación y timeout.
- Proveedores `sim`, Ollama y OpenAI-compatible.
- MCH persistente: lifecycle, health, autostart y límite de reinicios.
- Módulos `.hlimod` con firma Ed25519 opcional, trust store y políticas.
- Migraciones versionadas con backup y verificación.
- CLI, TUI y servidor MCP stdio.
- Paquete Windows x86_64, instalador y desinstalador por usuario.

## Limitaciones

- Linux experimental: gates de integración no portados.
- Sin sandbox completo ni shell seguro; `shell.execute` denegado.
- Sin routing económico general ni compatibilidad MCP universal.
- Gate visual manual de la TUI pendiente antes del tag.

## Instalación

Ver `QUICKSTART.md`. Verifica `checksums.sha256` antes de instalar.
