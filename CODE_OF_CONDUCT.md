# Código de conducta

Se espera respeto técnico y honestidad.

- Crítica al código, no a las personas.
- No se toleran acoso, discriminación ni ataques personales.
- Los desacuerdos se resuelven con evidencia reproducible.
- No se aceptan contribuciones que oculten fallos, falsifiquen gates o eliminen
  advertencias de seguridad sin justificación.

El mantenedor puede rechazar o retirar contribuciones que incumplan estas reglas.
