# Soporte

- Documentación: `README.md`, `QUICKSTART.md`, `docs/`.
- Problemas reproducibles: abre un issue con versión (`hli --version`), sistema,
  pasos y salida de `hli daemon status`.
- Seguridad: sigue `SECURITY.md`; no publiques detalles explotables.
- La Beta no ofrece SLA. Windows x86_64 es la plataforma probada; Linux es
  experimental.
